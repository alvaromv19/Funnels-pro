PASO 2 · Apps Script En el menú superior ve a Extensiones > Apps Script. Borra el código que aparece y pega el código de abajo.
PASO 3 · Implementar Haz clic en Implementar > Nueva implementación, elige tipo Aplicación web y en "Quién tiene acceso" elige Cualquier persona (Anyone).
PASO 4 · Conectar Copia la URL de la aplicación web que te entrega Google, pégala arriba y pulsa Enviar Fila de Prueba.
Código Completo para Google Apps Script (Code.gs) 
/**
 * GOOGLE APPS SCRIPT - DIAGNÓSTICO PRE-LLAMADA 1 A 1 CON MERCEDES RÍOS
 * Programa: Tu Ruta Financiera / Ruta 90 (LIFEOFNENA LLC)
 * 
 * INSTRUCCIONES:
 * 1. Pega este código en Extensiones > Apps Script dentro de tu nuevo Google Sheet.
 * 2. Guarda (Ctrl+S) y haz clic en "Implementar" > "Nueva implementación".
 * 3. Tipo: "Aplicación web" | Ejecutar como: "Yo" | Acceso: "Cualquier persona".
 * 4. Copia la URL generada y pégala en el formulario web.
 */

const SHEET_NAME = 'Diagnosticos_1a1';

function doPost(e) {
  const lock = LockService.getScriptLock();
  lock.tryLock(10000);

  try {
    const doc = SpreadsheetApp.getActiveSpreadsheet();
    let sheet = doc.getSheetByName(SHEET_NAME);

    // Si la pestaña no existe, la crea y formatea automáticamente con estilo ejecutivo
    if (!sheet) {
      sheet = doc.insertSheet(SHEET_NAME);
      const headers = [
        'Fecha y Hora',
        'ID Registro',
        'Ruta Estimada',
        'Llamadas Estimadas',
        'Nombre Completo',
        'Correo Electrónico',
        'Teléfono / WhatsApp',
        '1. SSN o ITIN',
        '2. ¿Desea Guía ITIN?',
        '3. Taxes Últimos 2 Años',
        '4. ¿Conoce Puntaje Crédito?',
        '5. Rango Puntaje Personal',
        '6. ¿Ayuda Monitoreo Gratis?',
        '7. Tarjetas/Préstamos Activos',
        '8. Colecciones/Bancarrota (2 años)',
        '9. ¿Tiene LLC Formada?',
        '10. Estado de la LLC',
        '11. ¿Tiene EIN?',
        '12. ¿Cuenta Bancaria Empresarial?',
        '13. Presencia Digital / Web',
        '14. Años Operando',
        '15. Ingreso Mensual Empresa',
        '16. Objetivos de la Asesoría',
        '17. Destino de la Inversión',
        '18. Capital Necesario',
        '19. Urgencia de Financiamiento',
        '20. Mayores Dudas / Preocupaciones',
        '21. Comodidad Trámites en Línea',
        '22. ¿Autoriza Revisar Reporte en Llamada?',
        '23. Disponibilidad 2-3 Llamadas Seguimiento',
        'Notas Adicionales Cliente',
        'Herramientas Recomendadas'
      ];
      sheet.appendRow(headers);
      sheet.setFrozenRows(1);

      // Estilo visual de cabecera (Verde Oscuro Ruta 90 + Texto Blanco/Dorado)
      const headerRange = sheet.getRange(1, 1, 1, headers.length);
      headerRange.setBackground('#0D2818');
      headerRange.setFontColor('#EFF6F0');
      headerRange.setFontWeight('bold');
      headerRange.setHorizontalAlignment('center');
    }

    // Parsear los datos enviados desde el formulario
    const rawData = e.postData ? e.postData.contents : '{}';
    const data = JSON.parse(rawData);

    const newRow = [
      new Date(),
      data.idRegistro || ('MR-' + new Date().getTime()),
      data.rutaEstimada || '',
      data.llamadasEstimadas || '',
      data.nombreCompleto || '',
      data.correoElectronico || '',
      data.telefonoWhatsapp || '',
      data.estatusFiscal || '',
      data.guiaItin || '',
      data.impuestos2Anios || '',
      data.conocePuntaje || '',
      data.rangoPuntaje || '',
      data.ayudaMonitoreo || '',
      data.tarjetasActivas || '',
      data.historialNegativo || '',
      data.tieneLLC || '',
      data.estadoLLC || '',
      data.tieneEIN || '',
      data.cuentaBancaria || '',
      data.presenciaDigital || '',
      data.aniosOperando || '',
      data.ingresoMensual || '',
      Array.isArray(data.objetivosAsesoria) ? data.objetivosAsesoria.join(' | ') : (data.objetivosAsesoria || ''),
      Array.isArray(data.destinoInversion) ? data.destinoInversion.join(' | ') : (data.destinoInversion || ''),
      data.capitalNecesario || '',
      data.urgenciaFinanciamiento || '',
      Array.isArray(data.dudasPrincipales) ? data.dudasPrincipales.join(' | ') : (data.dudasPrincipales || ''),
      data.comodidadDigital || '',
      data.autorizaRevision || '',
      data.disponibilidadLlamadas || '',
      data.notasAdicionales || '',
      data.herramientasRecomendadas || ''
    ];

    sheet.appendRow(newRow);

    // Colorear automáticamente la celda de Ruta Estimada para identificar rápido a las 11 personas
    const lastRow = sheet.getLastRow();
    const rutaCell = sheet.getRange(lastRow, 3);
    const rutaTexto = String(data.rutaEstimada || '');
    if (rutaTexto.indexOf('Express') !== -1) {
      rutaCell.setBackground('#1B7A34').setFontColor('#FFFFFF').setFontWeight('bold');
    } else if (rutaTexto.indexOf('Intermedia') !== -1) {
      rutaCell.setBackground('#D4AF37').setFontColor('#060807').setFontWeight('bold');
    } else {
      rutaCell.setBackground('#C42828').setFontColor('#FFFFFF').setFontWeight('bold');
    }

    return ContentService
      .createTextOutput(JSON.stringify({ status: 'ok', row: lastRow }))
      .setMimeType(ContentService.MimeType.JSON);

  } catch (error) {
    return ContentService
      .createTextOutput(JSON.stringify({ status: 'error', message: error.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  } finally {
    lock.releaseLock();
  }
}

function doGet() {
  return ContentService
    .createTextOutput(JSON.stringify({ status: 'active', service: 'Diagnóstico 1 a 1 Mercedes Ríos' }))
    .setMimeType(ContentService.MimeType.JSON);
}

Auditoría del Formulario y Clasificación

Cómo Clasifica este Formulario a tus Clientes en 3 Rutas

Hemos revisado y perfeccionado tus preguntas originales para que ninguna respuesta quede ambigua en Google Sheets y el sistema clasifique automáticamente a cada cliente antes de tu llamada 1 a 1:

1–2 Llamadas

Ruta Express

SSN o ITIN vigente, crédito personal > 680 sin colecciones, LLC activa con EIN y cuenta bancaria. Solo necesitan secuencia de lenders y destino de inversión.

3–4 Llamadas

Ruta Intermedia

Tienen LLC pero crédito personal regular (620–679), les falta activar cuenta bancaria/EIN o el negocio tiene menos de 1 año. Se trabaja reparación/optimización y Movimiento 1.5.

4–6 Llamadas

Ruta Desde Cero

No tienen ITIN/SSN, no tienen LLC aún, o el crédito personal está comprometido (< 620 o con colecciones). Primero regularización fiscal, formación de LLC y construcción desde la base.

Optimizaciones incluidas en tu formulario:

✓ Identificación Completa al Inicio: Nombre completo, Correo electrónico y WhatsApp obligatorios (además soporta pre-llenado automático por link personalizado ?nombre=Ana&email=ana@mail.com).

✓ Pregunta de Rango de Puntaje (>680): Se agregó el selector de rango crediticio en la Sección 2 para que el algoritmo detecte automáticamente si el cliente supera los 680 puntos requeridos por la Ruta Express.

✓ Rangos Monetarios Claros: En ingresos mensuales ($2,000–$5,000 / $5,000–$10,000) y capital requerido ($10,000–$25,000 / $25,000–$50,000 / $50,000–$100,000) se definieron los intervalos exactos para evitar confusiones al elegir.

✓ Callouts Inteligentes Integrados: Las recomendaciones de MyFreeScoreNow, Firstcard y SmartCredit aparecen automáticamente como tarjetas de alto valor sin ensuciar las opciones de respuesta.
